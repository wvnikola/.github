## Clouding Bar

Every Claude chat at a glance on your Mac: on the Touch Bar, in a floating pill or in the notch.
See which chats are working and which are done, how full the context and the 5-hour limit are,
and answer Claude's permissions and questions without switching windows.

- **Download:** [Clouding Bar for Mac (.dmg)](https://github.com/wvnikola/clouding-bar/releases/latest/download/Clouding-Bar.dmg), signed and notarized
- **Claude Code plugin:** `/plugin marketplace add wvnikola/clouding-bar`, then `/plugin install clouding-bar@clouding-bar`
- **Source:** [wvnikola/clouding-bar](https://github.com/wvnikola/clouding-bar)

No account, no analytics, no server of ours. Contact: [t.me/wvnikola](https://t.me/wvnikola)
